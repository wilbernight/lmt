# دفتر (Daftar)

سامانه مدیریت کار تیمی، الهام‌گرفته از میزیتو، روی **Laravel 12 + Inertia + Vue 3 + Tailwind 4**.
راست‌به‌چپ، فارسی، تقویم شمسی، حالت تاریک/روشن.

## امکانات

| بخش | امکانات |
|---|---|

| داشبورد | کارهای امروز، تأخیرها، پیگیری از دیگران، پرمشغله‌ترین همکار، آخرین نامه‌ها، یادداشت‌های سنجاق‌شده |

| وظایف | مسئولان، ناظران، اولویت، مهلت و تاریخ شروع (شمسی)، دسته‌بندی، برچسب، چک‌لیست با درصد پیشرفت، گزارش با منشن و پیوست، تاریخچه، نشان‌گذاری، تقویم ماهانه شمسی، چاپ |

## امنیت

- **احراز هویت:** Fortify؛ ورود دومرحله‌ای (TOTP + کدهای بازیابی)، تأیید ایمیل، تأیید دوباره رمز برای بخش‌های حساس، سیاست رمز قوی (در production با بررسی رمزهای لو رفته).
- **محدودیت نرخ:** ورود (به ازای حساب+IP و به ازای IP)، 2FA، ثبت‌نام، بازیابی رمز، آپلود، پیام، دعوت، جستجو و همه درخواست‌ها.
- **عدم افشای حساب‌ها:** پاسخ بازیابی رمز برای ایمیل موجود و ناموجود یکسان است؛ میزکار برای غیرعضو «پیدا نشد» (۴۰۴) برمی‌گرداند.
- **کنترل دسترسی:** Policy برای هر مدل، اتصال تودرتوی مسیرها (scoped bindings) جلوی IDOR بین میزکارها را می‌گیرد، شناسه‌ها ULID هستند (قابل حدس نیستند)، فیلدهای حساس فقط سمت سرور مقدار می‌گیرند (mass assignment بسته است).
- **هدرها:** CSP سخت‌گیرانه با nonce (بدون `unsafe-inline` برای اسکریپت)، `X-Frame-Options: DENY`، `nosniff`، `Referrer-Policy`، `Permissions-Policy`، COOP/CORP و HSTS روی HTTPS.
- **فایل‌ها:** خارج از پوشه عمومی با نام تصادفی ذخیره می‌شوند، نوع فایل از محتوای آن تشخیص داده می‌شود (نه پسوند)، SVG/HTML/PHP رد می‌شوند، دانلود فقط بعد از بررسی دسترسی و با `Content-Disposition: attachment`.
- **XSS:** همه محتوای کاربر به‌صورت متن ساده نمایش داده می‌شود (بدون `v-html`)، لینک‌های وب‌سایت فقط http/https.
- **نشست:** رمزنگاری‌شده، HttpOnly، SameSite، مشاهده نشست‌های فعال و خروج از سایر دستگاه‌ها.
- **ثبت رخداد:** ورود، ورود ناموفق، قفل، تغییر نقش، حذف و خروجی گرفتن در `audit_logs` با IP ثبت می‌شود.
- **CSV:** در خروجی مشتریان جلوی Formula Injection گرفته شده است.
- **پایگاه داده:** کاربر جداگانه با دسترسی محدود به همین دیتابیس (نه root).

## اجرا (محلی)

پیش‌نیاز: PHP 8.2+، Composer، Node 20+، MariaDB/MySQL.

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

برای گفتگو و برد زنده، در ترمینال دیگری:

```bash
php artisan reverb:start --port=8081
```

حساب‌های نمایشی را seeder می‌سازد (`database/seeders/DatabaseSeeder.php`)؛ رمز همه از `DEMO_PASSWORD` در `.env` خوانده می‌شود. این seeder در production اجرا نمی‌شود.

## تست‌ها

```bash
php artisan test
```

تست‌ها روی پایگاه داده `daftar_test` اجرا می‌شوند و شامل تست‌های امنیتی (IDOR، دسترسی‌ها، آپلود فایل، هدرها، محدودیت نرخ، عدم افشای حساب) هستند.

## چک‌لیست انتشار (production)

- `APP_ENV=production`، `APP_DEBUG=false`، یک `APP_KEY` جدید
- فقط HTTPS؛ `SESSION_SECURE_COOKIE=true` و `REVERB_SCHEME=https`
- رمزهای جدید و قوی برای دیتابیس و Reverb؛ `TRUSTED_PROXIES` اگر پشت پروکسی هستید
- `MAIL_*` واقعی برای ارسال تأیید ایمیل و دعوت‌نامه
- `php artisan config:cache route:cache view:cache` و `npm run build`
- `QUEUE_CONNECTION=database` و اجرای `php artisan queue:work` به‌عنوان سرویس
- فقط پوشه `public` در دسترس وب‌سرور باشد
- پشتیبان‌گیری منظم از دیتابیس و `storage/app/private`
